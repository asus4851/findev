# market-gen-ts

Эталонная TypeScript-версия генератора рыночных обновлений и песочница с графиком.

Логика сначала написана и проверена здесь, потому что TypeScript проще отлаживать и тестировать. Затем она перенесена в AssemblyScript (`../market-gen-as`): задание требует, чтобы случайность и логика цен работали в Wasm. Эта версия остаётся образцом поведения: тесты Wasm сравнивают его вывод с выводом этого эталона.

## Структура

```
src/
├── constants.ts              все числа модели: границы цен, проценты сдвига и спреда, диапазоны количеств
├── config/
│   └── simulation-config.ts  реэкспорт настроек запуска из ../../contracts (они общие с воркером и Angular)
├── model/                    что существует на рынке
│   ├── side.ts               покупка или продажа
│   ├── order.ts              рыночный ордер: купить или продать N штук
│   ├── quote.ts              верх стакана инструмента: bid, ask, количества, правила изменения
│   └── market-update.ts      результат: сделка плюс снимок стакана после неё
├── market-model/             правила, по которым рынок меняется
│   ├── price.ts              сдвиг цены, спред, стартовая цена
│   └── quantity.ts           количество на уровне стакана и размер ордера
├── simulator.ts              generateBatch: из ордеров, стакана и обновлений собирает батч
├── scheduler.ts              startSimulation: как часто генерировать батч (только в эталоне)
└── utils/
    └── random-generator.ts   генератор случайных чисел с seed

playground/                   локальная страница с графиком на Wasm-генераторе, не часть приложения
```

Каждая папка отвечает на один вопрос:

| Папка или файл | Вопрос |
|---|---|
| `config/` | С какими настройками запускаем? |
| `model/` | Что существует на рынке? |
| `market-model/` | По каким правилам это меняется? |
| `simulator.ts` | Как из этого собрать батч обновлений? |
| `scheduler.ts` | Как часто это делать? |
| `utils/` | Чем помочь, не зная о рынке? |

Тесты лежат рядом с кодом в файлах `*.spec.ts`.

## Что в Wasm, а что нет

- **В Wasm:** `model/`, `market-model/`, `simulator.ts`, `utils/random-generator.ts`, `constants.ts`.
- **Не переносилось:** `scheduler.ts`, потому что в Wasm нет таймеров. В приложении таймер генерации находится в воркере (`../worker/src/market-simulation.ts`), а `scheduler.ts` остался только в эталоне и его тесте.
- **Настройки** (`config/`) общие для воркера и Angular и лежат в `../contracts`.

## Модель рынка

У каждого инструмента по одному уровню стакана с каждой стороны: цена bid и ask и количество на них. Каждое обновление — это случайный рыночный ордер:

1. Покупатель берёт из ask, продавец отдаёт в bid.
2. Пока на уровне хватает количества, цены не меняются, а количество уменьшается на объём сделки.
3. Когда ордер больше уровня, цена сдвигается в сторону сделки на 0,05–0,15 %, стакан перестраивается вокруг новой цены, а сделка исполняется по новой цене.

Инварианты, которые проверяют тесты:

- цены в целых центах, от 1 цента до $1 000 000;
- bid всегда ниже ask;
- цена сделки всегда равна bid или ask того же обновления;
- количество сделки положительное, количества в стакане неотрицательные;
- одинаковый seed даёт одинаковые данные.

Известные упрощения:

- Когда ордер проходит уровень, вся сделка идёт по новой цене. Среднюю цену исполнения описано как TODO в `model/quote.ts`.
- Граница $1 000 000 выбрана так, чтобы в AssemblyScript все вычисления помещались в `i32`.

## Запуск

```bash
npm install
npm test            # тесты один раз
npm run test:watch  # тесты в режиме наблюдения
npm run typecheck   # проверка типов в строгом режиме
npm run playground  # собирает Wasm в ../market-gen-as и открывает http://localhost:5173/playground/
```

## Песочница с графиком

`playground/` — локальная страница, чтобы увидеть, как ведут себя цены. Генератор в ней работает в Wasm, собранном из `../market-gen-as`, а график рисует [lightweight-charts](https://github.com/tradingview/lightweight-charts) от TradingView. В приложение она не входит.

Страница ведёт себя как воркер:

- `playground/wasm-generator.ts` загружает `.wasm`, вызывает `init` и `nextBatch` и копирует буфер чисел в обновления;
- настройки проверяет `src/config`, потому что он даёт понятные тексты ошибок, а Wasm возвращает только биты;
- таймер и пауза работают на странице, потому что в Wasm таймеров нет.

Чтобы Vite мог отдать `.wasm` и настройки из соседних папок, в `vite.config.ts` разрешён доступ к `../market-gen-as/build` и `../contracts`.

Что можно делать:

- изменить seed и три настройки из ТЗ и нажать Apply, чтобы начать новый запуск;
- поставить на паузу и возобновить;
- выбрать инструмент для графика.

На графике красная линия — ask, зелёная — bid, синяя — цена сделки. Ось X — номер сделки инструмента, а не реальное время, чтобы была видна каждая сделка. Под графиком показаны метрики выбранного инструмента: последняя цена, спред, объём, VWAP, дисбаланс и сколько раз цена сдвигалась после исчерпания уровня.
