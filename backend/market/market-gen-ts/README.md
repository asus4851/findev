# market-gen-ts

Еталонна TypeScript-версія генератора ринкових оновлень.

Логіку спершу написано й перевірено тут, бо TypeScript простіше налагоджувати й тестувати. Потім її буде перенесено в AssemblyScript (`../market-gen-as`): завдання вимагає, щоб випадковість і логіка цін працювали у Wasm. Ця версія лишається як зразок поведінки і як джерело тестів для перенесення.

## Структура

```
src/
├── constants.ts              усі числа моделі: межі цін, відсотки зсуву і спреду, діапазони кількостей
├── config/
│   └── simulation-config.ts  налаштування запуску з ТЗ, їхні межі і перевірка
├── model/                    що існує на ринку
│   ├── side.ts               купівля чи продаж
│   ├── order.ts              ринковий ордер: купити або продати N штук
│   ├── quote.ts              верх стакана інструмента: bid, ask, кількості, правила зміни
│   └── market-update.ts      результат: угода плюс знімок стакана після неї
├── market-model/             правила, за якими ринок змінюється
│   ├── price.ts              зсув ціни, спред, стартова ціна
│   └── quantity.ts           кількість на рівні стакана і розмір ордера
├── simulator.ts              generateBatch: з ордерів, стакана й оновлень збирає батч
├── scheduler.ts              startSimulation: як часто генерувати батч
└── utils/
    └── random-generator.ts   генератор випадкових чисел із seed

playground/                   локальна сторінка з графіком на Wasm-генераторі, не частина застосунку
```

Кожна тека відповідає на одне питання:

| Тека чи файл | Питання |
|---|---|
| `config/` | З якими налаштуваннями запускаємо? |
| `model/` | Що існує на ринку? |
| `market-model/` | За якими правилами воно змінюється? |
| `simulator.ts` | Як з цього зібрати батч оновлень? |
| `scheduler.ts` | Як часто це робити? |
| `utils/` | Чим допомогти, не знаючи про ринок? |

Тести лежать поруч із кодом у файлах `*.spec.ts`.

## Що піде у Wasm, а що лишиться у воркері

- **У Wasm:** `model/`, `market-model/`, `simulator.ts`, `utils/random-generator.ts`, `constants.ts`.
- **У воркері на TypeScript:** `scheduler.ts`, бо у Wasm немає таймерів, і `config/`, бо налаштування перевіряються до запуску.

## Модель ринку

Кожен інструмент має один рівень стакана на кожному боці: ціну bid і ask та кількість на них. Кожне оновлення це випадковий ринковий ордер:

1. Покупець бере з ask, продавець віддає в bid.
2. Поки на рівні вистачає кількості, ціни не змінюються, а кількість зменшується на обсяг угоди.
3. Коли ордер більший за рівень, ціна зсувається в бік угоди на 0,05–0,15%, стакан перебудовується навколо нової ціни, а угода виконується за новою ціною.

Інваріанти, які перевіряють тести:

- ціни в цілих центах, від 1 цента до $1 000 000;
- bid завжди нижчий за ask;
- ціна угоди завжди дорівнює bid або ask того самого оновлення;
- кількість угоди додатна, кількості в стакані невід'ємні;
- однаковий seed дає однакові дані.

Відомі спрощення:

- Коли ордер проходить рівень, уся угода йде за новою ціною. Середню ціну виконання описано як TODO в `model/quote.ts`.
- Межа $1 000 000 обрана так, щоб в AssemblyScript усі обчислення вміщалися в `i32`.

## Запуск

```bash
npm install
npm test            # тести один раз
npm run test:watch  # тести в режимі спостереження
npm run typecheck   # перевірка типів у строгому режимі
npm run playground  # збирає Wasm у ../market-gen-as і відкриває http://localhost:5173/playground/
```

## Пісочниця з графіком

`playground/` це локальна сторінка, щоб побачити, як поводяться ціни. Генератор у ній працює у Wasm, зібраному з `../market-gen-as`, а графік малює [lightweight-charts](https://github.com/tradingview/lightweight-charts) від TradingView. У застосунок вона не входить.

Сторінка поводиться як майбутній воркер:

- `playground/wasm-generator.ts` завантажує `.wasm`, викликає `init` і `nextBatch` та копіює буфер чисел в оновлення. Такий самий адаптер знадобиться у воркері застосунку;
- налаштування перевіряє `src/config`, бо він дає зрозумілі тексти помилок, а Wasm повертає лише біти;
- таймер і пауза працюють на сторінці, бо у Wasm таймерів немає.

Щоб Vite міг віддати `.wasm` із сусідньої теки, у `vite.config.ts` дозволено доступ до `../market-gen-as/build`.

Що можна робити:

- змінити seed і три налаштування з ТЗ та натиснути Apply, щоб почати новий запуск;
- поставити на паузу і відновити;
- вибрати інструмент для графіка.

На графіку червона лінія це ask, зелена bid, синя ціна угоди. Вісь X це номер угоди інструмента, а не реальний час, щоб було видно кожну угоду. Під графіком показано метрики вибраного інструмента: остання ціна, спред, обсяг, VWAP, дисбаланс і скільки разів ціна зсувалась після вичерпання рівня.
